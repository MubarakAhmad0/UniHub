# UniHub — Role-Based Feature Specs

This directory contains per-page feature specifications for three user roles:

| Role | Description |
|---|---|
| **Student** | Enrolled university student (current baseline build) |
| **Lecturer** | Faculty/teaching staff member |
| **Admin** | University administration staff |

## Convention used in each file

- ✅ Feature exists in current student build
- 🆕 New feature that needs to be added for this role
- 🚫 Feature not available / hidden for this role
- 🔒 Read-only access (can see, cannot modify)
